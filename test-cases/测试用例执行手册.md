# 智能求职辅助系统 测试用例执行手册

| 项目 | 内容 |
| --- | --- |
| 用途 | 照着本手册逐条操作即可完成对系统的功能测试，并记录结果 |
| 被测系统 | 智能求职辅助系统（`job-assistant-1.0.0.jar`，源码 `C:\soft\job-assistant`） |

## 1 使用说明

### 1.1 怎么用这份文档

1. 先按第 2 章把环境起起来（数据库 → 启动服务 → 健康检查）；
2. 按第 3 章准备测试数据（演示账号、简历与岗位样例、敏感信息样例）；
3. 从第 4 章开始逐条执行：每条用例给出了"操作步骤与输入"和"预期结果"，执行后把实际现象填进最后一列；
4. 主流程联调用第 5 章的场景剧本（剧本是按用户真实使用顺序串起来的）；
5. 想省时间可用第 6 章的自动化脚本先跑一遍，再用本手册做人工复核；
6. 发现问题按第 7 章模板记录，修完后按"回归范围"重跑相关用例。

### 1.2 优先级与判定

| 优先级 | 含义 | 执行建议 |
| --- | --- | --- |
| P0 | 主流程、阻塞级功能（登录、简历、分析、面试、报告） | 必须执行，必须通过 |
| P1 | 重要分支与异常处理（校验、越权、降级、版本） | 必须执行 |
| P2 | 体验与边界（分页、超长、特殊字符、样式） | 时间允许时执行 |

**单条用例判定"通过"需同时满足**：

- 页面无白屏、无 JS 报错，提示文案与预期一致；
- 接口返回 `code=200`（异常用例返回文档中约定的错误码），`msg` 可读；
- 落库/回显的数据与操作一致（刷新页面后仍在）；
- 该脱敏的地方脱敏、该拒绝的地方拒绝、该降级的地方带"本地降级"标记；
- 无 HTTP 500、无请求长时间无响应（AI 场景允许 20 秒内返回）。

### 1.3 环境变量与约定

| 约定 | 值 |
| --- | --- |
| 服务地址 | `http://127.0.0.1:8082`（若 `application.yml` 改过端口，以实际为准） |
| 前端入口 | `http://127.0.0.1:8082/`（落地页）→ 进入 `/job/index.html` |
| 演示账号 | 求职者 `jobuser/123456`；管理员 `admin/123456` |
| 鉴权方式 | 登录后前端存令牌，请求头 `Authorization: Bearer <token>` |
| 大模型 | 需环境变量 `DASHSCOPE_API_KEY`；未配置时相关用例应走本地降级 |
| 向量库 | `MILVUS_HOST`/`MILVUS_PORT`（默认 `192.168.100.200:19530`）；不可用时 RAG 自动降级 |

## 9 常见问题与判读

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 所有接口返回 401 | 没带令牌 / 令牌过期 / 登录失败 | 重新登录；确认请求头 `Authorization: Bearer <token>` |
| 管理端接口 403 | 用的是普通用户令牌 | 换 `admin` 登录 |
| 分析/面试返回"本地降级" | 未配置 `DASHSCOPE_API_KEY`、网络不通、超时或限流 | 配置密钥并重启；或按降级用例判定通过 |
| 新建简历耗时约 3 秒 | Milvus 不可达，触发连接超时后短路 | 正常；启动 Milvus 或设 `--job.vector.enabled=false` 可消除 |
| 页面中文乱码 | 响应未声明 UTF-8 / 文件编码非 UTF-8 | 确认接口 `Content-Type` 含 `charset=UTF-8`；文本文件用 UTF-8 |
| 启动失败提示端口占用 | 8082/8080 已被占用 | `--server.port=8083` 换端口，或结束占用进程 |
| 登录 500 / 表不存在 | 没执行 `sql/schema.sql` | 重新初始化数据库 |
| `mvn test` 离线失败 | 本地仓库缺 surefire 依赖 | 先联网执行一次 `mvn test` 预热依赖 |
